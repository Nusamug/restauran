# 🍽️ Sistema Integrado de Gestión para Restaurante (Sabor & Gestión)

## 📌 Descripción del Proyecto
Plataforma web integral para la administración de un restaurante que abarca la toma de pedidos en mesas (Comanda/Carrito), el módulo de cobro y facturación (Cajero), la administración del menú digital y la gestión de usuarios por roles.

Este proyecto integra los resultados de aprendizaje de tres asignaturas:
1. **Metodologías Ágiles:** Gestión del proyecto bajo el marco de trabajo Scrum utilizando GitHub y Markdown.
2. **Frontend I:** Interfaz Web Responsive (1920px, 786px, 460px) interactiva con HTML5, CSS3 y JavaScript Vanilla (DOM, POO, Métodos de Array).
3. **Backend:** Arquitectura Orientada a Objetos en Java con Interfaces, colecciones (ArrayList), operaciones CRUD y menú interactivo por consola.
